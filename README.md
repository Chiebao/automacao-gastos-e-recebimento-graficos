# 📊 Dashboard Financeiro  

Sistema em **Python (Tkinter + SQLite + Matplotlib)** para gestão de finanças pessoais.  
Permite **cadastrar, editar e excluir registros** de entradas e saídas, com armazenamento em banco de dados e geração de **gráficos dinâmicos**.

---

## 🚀 Funcionalidades

- Cadastro de serviços (entradas e saídas)  
- Edição e exclusão de registros  
- Armazenamento em **SQLite**  
- Gráficos de acompanhamento em tempo real  
- Interface responsiva com **CustomTkinter**  

---

## 🛠️ Tecnologias Utilizadas

- Python 3.12+  
- Tkinter / CustomTkinter  
- SQLite3  
- Matplotlib  

---

## 📈 Objetivo do Projeto

O projeto foi desenvolvido para consolidar habilidades em:  
- Criação de interfaces gráficas em Python  
- Integração com banco de dados  
- Manipulação e análise visual de dados
